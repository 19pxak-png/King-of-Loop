# 40 FPS Gang Bot — Pterodactyl

## สิ่งที่มีในชุดนี้
- สร้าง 9 หมวดและห้องพื้นฐานด้วยปุ่มคำสั่ง `/setup-40fps`
- แผงปุ่มหลัก: สวัสดิการ, เช็กพีคไทม์, แจ้งลา, สตอรี่, บัญชีแก๊ง, King of Loop
- บันทึกข้อมูลลง `data/db.json`
- คำสั่ง `/setup-40fps`, `/panel-40fps`, `/รายงานพีคไทม์`
- ระบบใช้ Discord.js v14 และ Node.js 20+

## สำคัญก่อนติดตั้ง
1. สำรองไฟล์/ข้อมูลบอทเดิมก่อน ห้ามลบโปรเจกต์เดิมจนกว่าจะทดสอบตัวใหม่นิ่ง
2. อย่าแชร์ `DISCORD_TOKEN` ให้ผู้อื่น และอย่าใส่ Token ในห้อง Discord
3. บอทต้องมีสิทธิ์ Manage Channels, Send Messages, Embed Links, Read Message History, Use Application Commands
4. เชิญบอทด้วย OAuth2 scopes `bot` และ `applications.commands`
5. บอทนี้เป็นโปรเจกต์แยกเพื่อแก้ปัญหาไฟล์ `src/index.js` หาย ไม่สามารถผสานซอร์สเดิมที่ไม่มีอยู่ในชุดไฟล์นี้ได้โดยอัตโนมัติ

## ติดตั้งบน Pterodactyl ทีละคลิก
1. ดาวน์โหลด ZIP แล้วแตกไฟล์ในเครื่อง
2. เปิด File Manager ของเซิร์ฟเวอร์ Pterodactyl
3. สำรอง/ดาวน์โหลดไฟล์เดิมก่อน
4. อัปโหลดไฟล์และโฟลเดอร์จากใน ZIP ให้โครงสร้างเป็น:
   - `package.json`
   - `.env`
   - `src/index.js`
   - `src/config.js`
   - `data/db.json`
5. สร้างไฟล์ `.env` โดยคัดลอกจาก `.env.example` แล้วใส่ค่าจริง
6. ใน Startup ให้ใช้ `npm start` (ถ้าแผงโฮสต์ใช้คำสั่ง Start Command ให้ระบุ `npm start`)
7. กด Reinstall/Install Dependencies หากแผงโฮสต์มีตัวเลือก หรือรัน `npm install`
8. กด Start แล้วดู Console ต้องเห็น `Ready as ...`
9. ใน Discord ใช้ `/setup-40fps` เพื่อสร้างหมวด/ห้อง และ `/panel-40fps` เพื่อโพสต์แผงปุ่ม

## หมายเหตุการทำงาน
- การสร้างห้องจะข้ามห้องชื่อเดิมในหมวดเดิม ไม่สร้างซ้ำ
- ระบบข้อมูลเก็บใน JSON บนดิสก์ของเซิร์ฟเวอร์ ถ้ารีเซ็ต/ลบไฟล์ `data/db.json` ข้อมูลอาจหาย
- ปุ่มที่เป็นการจัดการบัญชี/รีเซ็ตคะแนนจำกัดสิทธิ์ไว้เฉพาะบทบาทหัวหน้า/รองหัวหน้าตามชื่อใน `.env`
- ระบบส่ง DM อาจล้มเหลวหากสมาชิกปิดรับ DM จากสมาชิกเซิร์ฟเวอร์
- ทดสอบในเซิร์ฟเวอร์สำรองก่อนใช้งานจริง
